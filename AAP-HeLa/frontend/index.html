Agent Audit Protocol (AAP)

Transparent, Explainable, and Governable AI Trading on HeLa Chain

Problem Statement #4 HeLa Chain · ID 666/8668 LangGraph + Gemini ZK-SNARK · Groth16

Problem

Autonomous agents increasingly make high-stakes financial decisions — BUY/SELL orders worth lakhs of rupees — with no standardized way to verify why a decision was made, who made it, or whether it can be trusted. No audit trail. No human override. No tamper-proof record.

Solution Architecture

Off-Chain

  • LangGraph + Gemini 1.5 Pro agent
  • 20+ technical indicators (RSI, MACD, Bollinger)
  • News sentiment analysis
  • Multi-factor risk scorer
  • PDR builder + pre-validator
  • IPFS upload via Pinata
  • Merkle tree batcher
→

On-Chain (HeLa)

  • AuditAnchor.sol — Merkle roots
  • ChallengeRegistry.sol — disputes
  • PolicyRegistry.sol — DAO rules
  • AgentRegistry.sol — DID + stake
  • 24h challenge window
  • Bond staking + slashing
  • DAO token voting

5 Key Innovations

01

Linked Hash Chain

Each PDR contains prev_pdr_hash of the prior record. Any insertion or deletion is cryptographically detectable — like a blockchain for agent decisions.

02

Bond Staking Challenges

Challengers stake 0.005 HELA to raise a dispute. Returned + reward if upheld. Burned if dismissed. Eliminates challenge spam while incentivizing legitimate oversight.

03

3-Level Verification

L1: Hash integrity. L2: Deterministic replay (same inputs → same output). L3: ZK-SNARK proof (prove rules followed without revealing private data).

04

Privacy-Preserving Logs

Logs contain trade data, reasoning, risk scores — zero PII. No user name, account number, or portfolio size. Agent DID is pseudonymous by design.

05

Policy-Based Approval Gate

Auto-approve <₹10,000. Manual review ₹10K–1L. Block above risk threshold 0.80. User-configurable limits. DAO votes to change thresholds.
